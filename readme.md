# Calcolatori Elettronici – Laboratori

Questa repository contiene i laboratori e le esercitazioni svolte durante il corso di **Calcolatori Elettronici** al Politecnico di Torino.

## 📚 Descrizione

Il corso tratta temi legati all’architettura dei calcolatori, linguaggi a basso livello e programmazione in assembly.  
I laboratori si concentrano sull’utilizzo di un simulatore e sull’implementazione di algoritmi in linguaggio assembly.

> ⚠️ I testi ufficiali degli esercizi non sono inclusi in questa repository per rispettare il diritto d’autore dell’ateneo.

## 📁 Contenuto della repo

- `lab1/`, `lab2/`, ... – Soluzioni dei laboratori settimanali
- `relazioni/` – Eventuali brevi spiegazioni o commenti scritti da me
- `README.md` – Questo file

## 🛠️ Strumenti utilizzati

- Simulatore **MARIE** (MarieSim)
- Editor di testo (VS Code, Eclipse, ecc.)
- Sistema operativo: Linux / Windows
